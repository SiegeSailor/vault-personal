Research project proposal for class **MET CS 575** at Boston University, instructed by **Dr. Nourai**. Student [Zhang, Jin Yu](siege@bu.edu) submitted on **October 28, 2022**.

## Operating System Deadlock

Since there is no efficient solution for OS deadlocks and the existing ones (prevention, avoidance, detection, recovery) are not really implemented in modern OS, I want to discuses some attempts to solve OS deadlocks in some **restricted** situation with **reasonable** costs.

The context would include but not limited to existing solutions/algorithms(and what method they use), the overview for the attempt to solve OS deadlocks, what restricted situation can the attempt work, the cost for the attempt compare to current ones, and real-world possible implementations.
