# Proof

## Direct proof

A \implies B
start with A -> A1 -> A2 -> ... -> B

Exple: If an integer n is divisible by 12 then n is divisible by 3.
hypothesis A: n is divisible by 12
conclusion B: n is divisible by 3
n is divisible by 12 -> n = 12 \times K (A1...) -> n = (3 \times 4) \times K -> n = 3 \times (4 \times K)
-> n = 3 \times L, n is divisible by 3 (B)

## Proof by contraposition

Instead of working with A \implies B, we work with \neg B \implies \neg A

Exple: If an integer n is not divisible by 3 then n is not divisible by 12 === If an integer n is divisible by 12 then n is divisible by 3

## Proof by contradiction

Suppose A \implies B
Assume A is true and \neg B is true
and then derive a contradiction or an absurd statement

Exple: If an integer n added to itself yields n then n is zero.
n + n = n (A) \implies n = 0 (B)
Assume ( n + n = n ) \land ( n \ne 0 )

1. n + n = n -> n + n - n = n - n -> n + 0 = 0 -> n = 0 (Contradiction to n \ne 0)
2. n + n = n -> 2n = n -> \frac{2n}{n} = \frac{n}{n} (doable because we already assume n \ne 0) -> 2 = 1 (Absurd)
