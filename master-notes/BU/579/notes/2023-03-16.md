## SELECT

- v in V: return true if v is in V
- EXISTS (SELECT ...): return true if the select statement returns at least one tuple
- NOT EXISTS
- 2 < ANY (SELECT ...)
- 2 < ALL (SELECT ...)
- SELECT name FROM employee WHERE salary < ALL (SELECT salary FROM manager)
- If the nested sub query has no relation to the outer, the sub one will only execute once
  - Once: `SELECT name FROM employee WHERE number IN (SELECT digit FROM department WHERE bill = 'Research')`
  - Number of _employee_ tuples: `SELECT name FROM employee WHERE number IN (SELECT digit FROM department WHERE employee.bill = department.bill)`
- EXCEPT: `{1,2,3}` - `{2,3}` = `{1}` Return tuples that don't show up in the latter one
- `Employee e` as same as `Employee AS e`
- Joins:
  - `SELECT * FROM a, b WHERE a.z=b.z`
  - `SELECT * FROM a JOIN b ON a.z=b.z`
  - `SELECT * FROM a NATURAL JOIN b`
    - `NATURAL JOIN` will compare all columns with the same name while `WHERE` and `JOIN ON` only compare written conditions
  - Only use `WHERE` or `NATURAL JOIN` if the column names are the same
