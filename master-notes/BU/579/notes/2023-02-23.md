# SQL

In relational data model, Relation is a set of tuples, hence doesn't allow duplicated data. However, SQL allows duplicates (results from `SELECT`, especially for specific columns. Use `DISTINCT` keyword before the column name to prevent it).

## Set Operations

> MySQL doesn't implement `INTERSECT` but `UNION` and `EXCEPT` (difference)

### Compatibility Condition:

- Number of columns in T1 must be as same as T2
- Data types of corresponding columns must be identical (or compatible)
- Duplicates are automatically removed from set operations, but it depends on implementation
- For `ORDER BY`, `ASC` is default.
