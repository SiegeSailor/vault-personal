# SQL

In relational data model, Relation is a set of tuples, hence doesn't allow duplicated data. However, SQL allows duplicates (results from `SELECT`, especially for specific columns. Use `DISTINCT` keyword before the column name to prevent it).

## Set Operations

> MySQL doesn't implement `INTERSECT` but `UNION` and `EXCEPT` (difference)

### Compatibility Condition:

- Number of columns in T1 must be as same as T2
- Data types of corresponding columns must be identical (or compatible)
- Duplicates are automatically removed from set operations, but it depends on implementation
- For `ORDER BY`, `ASC` is default.

## In-Class Practice

```sql
USE company;
SELECT project.pnumber, project.pname FROM project WHERE plocation = 'Stafford';
SELECT dependent_name FROM dependent, employee WHERE dependent.essn = employee.ssn AND employee.fname = 'John' AND employee.lname = 'Smith';
SELECT employee.fname, employee.lname FROM employee, department WHERE employee.dno = department.dnumber AND department.dname = 'Research' AND employee.bdate > '1960-01-01';
SELECT employee.fname, employee.lname FROM employee, works_on, project WHERE project.plocation = 'Houston' AND works_on.pno = project.pnumber AND employee.ssn = works_on.essn;
SELECT employee.fname, employee.lname FROM employee, department, project WHERE employee.ssn = department.mgrssn AND department.dnumber = project.dnum AND project.pname = 'ProductX';
SELECT department.dname FROM department, dept_locations, project WHERE department.dnumber = dept_locations.dnumber AND dept_locations.dnumber = project.dnum AND dept_locations.dlocation = 'Houston' AND project.pname = 'Reorganization';
(SELECT employee.fname, employee.lname FROM employee, department WHERE employee.dno = department.dnumber AND department.dnumber = 5) UNION (SELECT employee.fname, employee.lname FROM employee,department WHERE employee.ssn = department.mgrssn);
```
