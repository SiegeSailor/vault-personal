- Default length for `CHAR` is `1`
- Default length for `VARCHAR` is `80`
- We can define constraint for constraints such as `constraint proj_number foreign key (pno) references project (pnumber)`. In this case, the auto-generated name doesn't exist
- We can drop the constraint by `DROP constraint proj_number` or `DROP constraint <auto_generated_name>`
- We can define **Domain** with existing types and **Type** with user-defined objects
- **DBA**: Database Administrator
- **Vertical SELECT**: Projection. Such as `SELECT name,department FROM employee`
- **Horizontal SELECT**: Selection. Such as `SELECT * FROM employee WHERE ssn="123123123"`

## Join Query

```sql
SELECT employee.name FROM employee, department WHERE department.name = "HR" AND employee.department_number = department.number;
```

What databases do behind the scene:

1. Create a cartesian product of all tables in from clause
2. Exam all tuple in the cartesian product one at a time and select those that satisfy the condition in the whole clause
3. Project over the columns in the selected clause
