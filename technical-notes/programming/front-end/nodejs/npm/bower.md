## Overview

bower 在 0.9.0 版以前可以使用 component.json，但是為了避免跟其他工具命名衝突，故 0.9.0 以後版本請改為 bower.json。bower 是 Twitter 團隊開發的一套網頁工具，用來管理或安裝 Web 開發所需要的 Package，像是 CSS 和 JavaScript，也可以依據套件的相依性來安裝，簡單來說，開發者不用再去煩惱套件相依性問題，以及時間久了想更新最新版本，還要到各 Package 網站來下載，這些步驟都省了，一個指令就可以全部做完上述的步驟。
