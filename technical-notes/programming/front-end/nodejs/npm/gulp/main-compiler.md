# 套件註記

## 重要更新

因各套件各自的升級，一些 Config 檔可能已經無法正常使用，以下是一些必須注意的套件。

{% hint style="info" %}
[Gulp-Babel](https://www.npmjs.com/package/gulp-babel)。注意若要使用於 React，須額外載入 @babel/preset-react。
{% endhint %}

{% hint style="info" %}
[Gulp-Load-Plugins](https://www.npmjs.com/package/gulp-load-plugins)。增進 Gulp 使用體驗。
{% endhint %}

{% hint style="info" %}
[Gulp-GH-Pages](https://www.npmjs.com/package/gulp-gh-pages)。Sync GitHub Page 用。
{% endhint %}

{% hint style="info" %}
[Gulp-Clean-CSS](https://www.npmjs.com/package/gulp-clean-css)。處理 CSS 用，Gulp-Minify-CSS 的替代。
{% endhint %}

{% hint style="info" %}
[UglifyJS](https://github.com/mishoo/UglifyJS2#minify-options)。或可替代 Gulp-Uglify。
{% endhint %}

{% hint style="info" %}
[Main-Bower-Files](https://www.npmjs.com/package/main-bower-files)。用於取出 Bower 內專案的特定檔案。
{% endhint %}

{% hint style="warning" %}
Bower 現在使用會出現 _**bower@1.8.8: We don't recommend using Bower for new projects. Please consider Yarn and Webpack or Parcel. You can read how to migrate legacy project here: https://bower.io/blog/2017/how-to-migrate-away-from-bower/**_，日後須考慮替代方案。
{% endhint %}
