# PIP

![PIP](../../../../.gitbook/assets/image.png)

## Overview

PIP is a de facto standard package-management system used to install and manage software packages written in Python. Many packages can be found in the default source for packages and their dependencies — Python Package Index \( PyPI \). Most distributions of Python come with pip preinstalled. Python 2.7.9 and later \( on the python2 series \), and Python 3.4 and later include pip \( pip3 for Python 3 \) by default. pip is a recursive acronym for Pip Installs Packages.
