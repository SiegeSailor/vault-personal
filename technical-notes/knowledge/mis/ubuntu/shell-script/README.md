# Shell Script

![Shell Script](../../../../.gitbook/assets/shellscript-128x128-circle.png)

## Overview

又稱 Shell 命令稿、程式化指令碼，是一種電腦程式使用的文字檔案，內容由一連串的 Shell 命令組成，經由 Unix Shell 直譯其內容後運作。被當成是一種手稿語言來設計，其運作方式與直譯語言相當，由 Unix Shell 扮演命令行直譯器的角色，在讀取 Shell 指令碼之後，依序執行其中的 Shell 命令，之後輸出結果。利用 Shell 指令碼可以進行系統管理，檔案操作等。
