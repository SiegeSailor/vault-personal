# Get Started

## Precondition

* Node.js ::
* NPM ::
* Semantic UI ::
* jQuery ::

## Init

**Semantic UI** is Gulp a based CSS framework, you need to run the following command with your **package.json** in your Semantic folder.

```bash
npm install
```

Then after that, you need to use the Gulp command which are set by Semantic as default, here is the first one you should do. Notice that you have to use `npx` to use Gulp globally.

```bash
npx gulp build
```
